```bash
atlas deploy
```

Builds your Docker images. Pushes to GHCR. Deploys to your cluster. Configures DNS. Provisions HTTPS. Done.

## What happens

1. Reads `atlas.yaml` to find services
2. Builds Docker images for each service
3. Pushes to `ghcr.io/your-org/your-project`
4. Calls the Control Panel API to trigger deployment
5. Panel SSHs into the server and updates containers
6. Waits for rollout to complete
7. Creates/updates DNS records via Cloudflare

See [How Deploys Work](/docs/concepts/how-deploys-work) for the full pipeline.

## Options

| Flag | Description |
|------|-------------|
| `--tag` | Custom image tag (default: git SHA) |
| `--service, -s` | Deploy a specific service only |
| `--host` | Direct mode: deploy via SSH, skip Panel |
| `--yes, -y` | Non-interactive (CI mode) |

## Examples

```bash
atlas deploy                        # Deploy all services
atlas deploy --service api          # Deploy only the API
atlas deploy --host root@server     # Direct SSH deploy
atlas deploy --yes                  # CI mode
```
