## Project

| Command | Description |
|---------|-------------|
| `atlas create` | Scaffold a new project with atlas.yaml, Dockerfile, and CI workflow |
| `atlas init` | Add a service to an existing project |
| `atlas deploy` | Build, push, and deploy to the cluster |
| `atlas open` | Open a service URL in the browser |

## Operations

| Command | Description |
|---------|-------------|
| `atlas status` | TUI cluster dashboard |
| `atlas logs [service]` | Stream service logs |
| `atlas exec [service]` | Shell into a running container |
| `atlas restart [service]` | Rolling restart of a service |
| `atlas scale [service]` | Scale service replicas |

## Infrastructure

| Command | Description |
|---------|-------------|
| `atlas infra setup` | Provision a server with K3s, Swarm, or Firecracker |
| `atlas infra migrate` | Switch between runtimes |
| `atlas tunnel` | Start a Cloudflare Quick Tunnel for local development |

## Configuration

| Command | Description |
|---------|-------------|
| `atlas login` | Authenticate with GitHub OAuth |
| `atlas whoami` | Show current authentication status |
| `atlas env list` | List secret keys (values masked) |
| `atlas env set` | Set encrypted environment variables |
| `atlas env pull` | Download decrypted secrets to .env |

## Data

| Command | Description |
|---------|-------------|
| `atlas db migrate` | Run database migrations |
| `atlas db studio` | Port-forward for Drizzle Studio |
| `atlas db psql` | Interactive PostgreSQL shell |
| `atlas db backup` | Export database with pg_dump |

## Environments

| Command | Description |
|---------|-------------|
| `atlas preview start` | Create an ephemeral environment from current branch |
| `atlas preview stop` | Destroy a preview environment |
| `atlas preview list` | List active preview environments |

## Panel

| Command | Description |
|---------|-------------|
| `atlas panel setup` | Connect CLI to a Control Panel instance |
| `atlas panel status` | Show Panel connection info and resources |
| `atlas panel config` | Configure GitHub App and Cloudflare credentials |
| `atlas panel server add` | Register a server with the Panel |
| `atlas panel server list` | List registered servers |

## CI mode

Every command supports `--yes` (or `-y`) for non-interactive execution. In this mode, prompts are skipped and output uses plain text with status prefixes:

```bash
atlas deploy --yes
atlas infra setup --host root@vps --domain myapp.com --runtime swarm --yes
```
