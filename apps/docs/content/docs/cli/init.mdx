## Usage

```bash
atlas init [options]
```

## Description

Adds a new service to an existing `atlas.yaml`. Prompts for service name, type, port, and Dockerfile path. Creates the Dockerfile if it does not exist.

## Options

| Flag | Description |
|------|-------------|
| `--name` | Service name |
| `--type` | Service type: `api`, `web`, or `worker` |
| `--yes, -y` | Non-interactive mode |

## Examples

```bash
atlas init                          # Interactive
atlas init --name worker --type worker --yes
```

## What it does

1. Reads the existing `atlas.yaml`
2. Prompts for service configuration
3. Appends the new service to `atlas.yaml`
4. Creates a Dockerfile template if one does not exist at the specified path
