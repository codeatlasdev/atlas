## Usage

```bash
atlas logs [service] [options]
```

## Description

Streams logs from running services. Connects to the Panel API via Server-Sent Events for real-time output.

## Options

| Flag | Description |
|------|-------------|
| `-f, --follow` | Stream logs continuously |
| `--tail N` | Number of recent lines to show (default: 100) |
| `--host` | SSH host (for direct mode) |

## Examples

```bash
atlas logs api -f           # Follow API service logs
atlas logs worker --tail 50 # Last 50 lines from worker
atlas logs -f               # Follow all logs
```

## How it works

1. CLI calls `GET /logs/project/:id?service={name}&tail={n}&follow={bool}`
2. Panel authenticates the request and resolves the project's server
3. Panel SSHs into the server and runs the appropriate log command:
   - K3s: `kubectl logs deployment/{service} --tail={n} -f`
   - Swarm: `docker service logs {stack}_{service} --tail {n} -f`
   - Firecracker: `curl --unix-socket /var/run/atlas-vmm.sock /vms/{stack}/{service}/logs`
4. Output streams back to the CLI as SSE events
