## Usage

```bash
atlas status [options]
```

## Description

Displays a real-time terminal dashboard with cluster information: runtime version, node status, running services, infrastructure components, and memory usage.

## Options

| Flag | Description |
|------|-------------|
| `--host` | SSH host (defaults to config) |

## Sections

| Section | Content |
|---------|---------|
| Runtime | K3s version, Docker Swarm status, or Firecracker VMM status |
| Nodes | Cluster nodes with ready/not-ready state |
| Services | Running pods or containers with replica counts |
| Infrastructure | Traefik, monitoring, ArgoCD status |
| Resources | Memory and CPU usage |

Press `q` to exit.
