## Usage

```bash
atlas tunnel [options]
```

## Description

Exposes your local development server to the internet via a temporary Cloudflare Quick Tunnel. Useful for testing webhooks, sharing work in progress, or accessing your local app from mobile devices.

## Options

| Flag | Description |
|------|-------------|
| `--port` | Local port to expose (auto-detected from atlas.yaml if omitted) |

## Examples

```bash
atlas tunnel              # Auto-detect port from atlas.yaml
atlas tunnel --port 3000  # Expose specific port
```

## How it works

1. Reads `atlas.yaml` to find the primary service port (or uses `--port`)
2. Starts a `cloudflared` Quick Tunnel pointing to `localhost:{port}`
3. Prints the temporary public URL
4. Tunnel stays active until you press Ctrl+C

The tunnel URL is temporary and changes on each invocation. For persistent tunnels, use `atlas infra setup --tunnel`.
