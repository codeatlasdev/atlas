The Control Panel is the brain. Every action — deploy, DNS, secrets, logs, provisioning — flows through this API.

## What it does

- **Deploys** applications to your servers via SSH
- **Manages DNS** automatically via Cloudflare API
- **Encrypts secrets** with AES-256-GCM and syncs to your cluster
- **Streams logs** via SSE
- **Provisions servers** with K3s or Swarm + full monitoring stack
- **Authenticates** users via GitHub OAuth + JWT

## Tech stack

| Component | Technology |
|-----------|-----------|
| Runtime | Bun |
| Framework | Elysia |
| RPC | oRPC (type-safe, shared types CLI ↔ Panel) |
| Database | PostgreSQL + Drizzle ORM |
| Auth | JWT (HMAC-SHA256) + GitHub OAuth |
| Encryption | AES-256-GCM via Web Crypto API |

## Multi-tenant

Everything is scoped by organization. Users belong to an org, servers belong to an org, projects belong to an org. Three roles:

| Role | Permissions |
|------|------------|
| `admin` | Everything — settings, servers, deploys, secrets |
| `dev` | Deploy, secrets, logs, preview environments |
| `viewer` | Read-only access |
