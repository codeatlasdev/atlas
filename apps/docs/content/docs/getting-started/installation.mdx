---
title: Installation
description: Install the Atlas CLI on Linux or macOS.
---

## Install script

```bash
curl -fsSL https://atlas.codeatlas.com.br/install.sh | bash
```

Downloads the latest binary for your platform and places it in `~/.atlas/bin`.

## Supported platforms

| OS | Architecture | Status |
|----|-------------|--------|
| Linux | x86_64 | Supported |
| Linux | ARM64 | Supported |
| macOS | Intel (x86_64) | Supported |
| macOS | Apple Silicon (ARM64) | Supported |

<Callout type="warn">
  Windows is not supported. Use WSL2 with a Linux distribution.
</Callout>

## Verify

```bash
atlas --help
```

## Build from source

Requires [Bun](https://bun.sh) 1.3 or later.

```bash
git clone https://github.com/codeatlasdev/atlas.git
cd atlas && bun install
bun run apps/cli/src/index.ts --help
```

To compile a standalone binary:

```bash
cd apps/cli && bun run build.ts
```

## Update

Re-run the install script. It replaces the existing binary.

```bash
curl -fsSL https://atlas.codeatlas.com.br/install.sh | bash
```
