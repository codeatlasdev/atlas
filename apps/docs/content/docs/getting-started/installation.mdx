---
title: Installation
description: Get Atlas running in 30 seconds.
---

```bash
curl -fsSL https://atlas.codeatlas.com.br/install.sh | bash
```

That's it. Downloads the latest binary for your platform and drops it in `~/.atlas/bin`.

**Supported platforms:** Linux x64/ARM64, macOS Intel/Apple Silicon.

Verify it works:

```bash
atlas --help
```

## Build from source

Requires [Bun](https://bun.sh) ≥ 1.3.

```bash
git clone https://github.com/codeatlasdev/atlas.git
cd atlas && bun install
bun run apps/cli/src/index.ts --help
```

## Update

Re-run the install script. It overwrites the old binary.

```bash
curl -fsSL https://atlas.codeatlas.com.br/install.sh | bash
```
