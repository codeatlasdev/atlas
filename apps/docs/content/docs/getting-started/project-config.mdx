title: Project Configuration
description: The atlas.yaml reference.
---

Every Atlas project has an `atlas.yaml` at the root. This file defines your services, domains, and infrastructure.

## Minimal example

```yaml
name: myapp
services:
  server:
    type: api
    port: 3000
    domain: myapp.com
```

## Full example

```yaml
name: myapp
org: my-org
domain: myapp.com

services:
  api:
    type: api
    dockerfile: ./Dockerfile
    port: 3001
    replicas: 2
    domain: api.myapp.com
    health: /health
    buildArg:
      NODE_ENV: production

  web:
    type: web
    domain: myapp.com

  worker:
    type: worker
    dockerfile: ./worker.Dockerfile

infra:
  postgres: true
  redis: true
  tunnel: true
```

## Reference

### Top-level fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ✓ | Project name. Used for namespaces and image tags. |
| `org` | string | | GitHub organization. Inferred from git remote if omitted. |
| `domain` | string | | Base domain for the project. |

### Service fields

Each key under `services` is a service name.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | `api` \| `web` \| `worker` | ✓ | Service type. Determines deploy behavior. |
| `dockerfile` | string | `./Dockerfile` | Path to Dockerfile. |
| `target` | string | | Docker build target stage. |
| `port` | number | | Port the service listens on. Required for `api` and `web`. |
| `replicas` | number | `1` | Number of replicas. |
| `domain` | string | | Public domain for this service. Triggers DNS + HTTPS setup. |
| `health` | string | | Health check endpoint path. |
| `buildArg` | object | | Docker build arguments. |

### Service types

| Type | What it does |
|------|-------------|
| `api` | Backend service. Gets Traefik routing, health checks, DNS. |
| `web` | Frontend service. Same as `api` but semantically different. |
| `worker` | Background worker. No ingress, no domain. Just runs. |

### Infrastructure fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `infra.postgres` | boolean | `false` | Deploy a PostgreSQL instance. |
| `infra.redis` | boolean | `false` | Deploy a Redis instance. |
| `infra.tunnel` | boolean | `false` | Use Cloudflare Tunnel instead of direct IP. |
