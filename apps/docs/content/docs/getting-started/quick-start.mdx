---
title: Quick Start
description: Zero to production in 5 minutes.
---

Three commands. That's it.

## 1. Authenticate

```bash
atlas login
```

Opens GitHub OAuth in your browser. Token stored locally at `~/.atlas/config.json`.

## 2. Provision a server

```bash
atlas infra setup --host root@your-vps
```

You'll pick a runtime:

```
? Container runtime
  ❯ Docker Swarm (lightweight, ~100MB overhead)
    K3s / Kubernetes (full-featured, ~512MB overhead)
```

Atlas SSHs into your server and installs everything: runtime, Traefik, HTTPS, monitoring.

<Callout type="info">
  See [Runtimes](/docs/concepts/runtimes) for a detailed comparison.
</Callout>

## 3. Deploy

```bash
cd your-project
atlas deploy
```

Builds, pushes, deploys, configures DNS, provisions HTTPS. Your app is live.

## What's next

```bash
atlas status              # TUI dashboard
atlas logs server -f      # Stream logs
atlas env set DB_URL=...  # Manage secrets
atlas preview start       # Preview environment per branch
```
