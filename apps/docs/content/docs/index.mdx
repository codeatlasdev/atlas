Atlas is an open-source **Internal Developer Platform** that turns any Linux server into a production-ready cluster. You write code — Atlas handles the rest.

## The problem

Deploying apps shouldn't require a PhD in Kubernetes. DNS, SSL, Docker, CI/CD, monitoring — it's a lot of moving parts just to get something live.

Managed platforms solved this, but at a cost: vendor lock-in, unpredictable pricing, and zero control over your infrastructure.

## The fix

Atlas gives you the managed-platform experience on **your own servers**. Any VPS — Hetzner, DigitalOcean, AWS, bare metal — becomes a fully managed platform.

```bash
atlas deploy   # that's it. DNS, HTTPS, scaling — automatic.
```

**What you never touch again:**

- Container orchestration — pick K3s or Docker Swarm, Atlas handles both
- DNS records and SSL certificates
- Secrets management (AES-256-GCM encrypted)
- Server provisioning
- Monitoring, logs, and alerting

## How it works

Define your services in `atlas.yaml`:

```yaml
name: myapp
services:
  api:
    type: api
    port: 3001
    domain: api.myapp.com
  web:
    type: web
    domain: myapp.com

infra:
  postgres: true
  redis: true
```

Atlas reads this and:

1. **Builds** Docker images for each service
2. **Pushes** to your container registry (GHCR)
3. **Deploys** to your cluster (K3s or Swarm)
4. **Configures DNS** via Cloudflare
5. **Provisions HTTPS** via Let's Encrypt
6. **Syncs secrets** encrypted at rest

## Architecture at a glance

```
You → atlas deploy → Control Panel API → Your Servers
                                              │
                                         Cloudflare
                                        (DNS + Proxy)
```

The **Control Panel** is the brain. The CLI talks to it. Every action — deploy, scale, restart — flows through the Panel API.
