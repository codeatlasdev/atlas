# Atlas Mobile

See [docs/mobile.md](../../docs/mobile.md) for setup, building, and pairing instructions.

`flutter run` installs **Atlas Dev** (id `br.com.codeatlas.atlas.mobile.dev`, orange icon) beside the store app; a store build is `flutter build appbundle|ipa --flavor prod` (fastlane does it). Details: [Dev and store apps](../../docs/mobile.md#dev-and-store-apps).
