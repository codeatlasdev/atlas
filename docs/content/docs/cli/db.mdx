## Usage

```bash
atlas db <subcommand> [options]
```

## Description

Manage the project database via SSH. Supports migrations, interactive shells, Drizzle Studio, and backups.

## Subcommands

### migrate

```bash
atlas db migrate
```

Runs pending database migrations on the remote server.

### studio

```bash
atlas db studio
```

Port-forwards the remote PostgreSQL to localhost and opens Drizzle Studio for visual database management.

### psql

```bash
atlas db psql
```

Opens an interactive PostgreSQL shell connected to the project database via SSH tunnel.

### backup

```bash
atlas db backup [options]
```

Exports the database using `pg_dump` and downloads the dump file to your local machine.

| Flag | Description |
|------|-------------|
| `--output, -o` | Local file path for the dump (default: `{project}-{date}.sql`) |

## Options (all subcommands)

| Flag | Description |
|------|-------------|
| `--host` | SSH host (defaults to config) |
| `--yes, -y` | Non-interactive mode |

## Examples

```bash
atlas db migrate                    # Run migrations
atlas db psql                       # Interactive shell
atlas db backup -o ./backup.sql     # Download backup
atlas db studio                     # Visual database browser
```
