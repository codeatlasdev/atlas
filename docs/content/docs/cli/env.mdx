## Usage

```bash
atlas env <subcommand> [options]
```

## Description

Manage secrets and environment variables for your project. All values are encrypted at rest with AES-256-GCM and synced to the cluster on every change.

## Subcommands

### list

```bash
atlas env list
```

Shows all secret keys for the current project. Values are masked.

### set

```bash
atlas env set KEY=VALUE [KEY2=VALUE2 ...]
```

Sets one or more secrets. Each value is encrypted before storage and immediately synced to the cluster runtime.

### pull

```bash
atlas env pull
```

Downloads all decrypted secrets to a local `.env` file in the current directory.

## Options

| Flag | Description |
|------|-------------|
| `--host` | SSH host (for direct mode) |
| `--yes, -y` | Non-interactive mode |

## Examples

```bash
atlas env set DATABASE_URL=postgres://user:pass@host/db
atlas env set REDIS_URL=redis://localhost:6379 API_KEY=sk-123
atlas env list
atlas env pull
```

## How sync works

After storing the encrypted value in the database, the Panel syncs to the cluster:

| Runtime | Method |
|---------|--------|
| K3s | `kubectl patch secret` with merge strategy |
| Swarm | `docker service update --env-add` on each service |
| Firecracker | `POST /vms/{stack}/{service}/env` via VMM socket |

Existing keys not included in the `set` command are preserved.
