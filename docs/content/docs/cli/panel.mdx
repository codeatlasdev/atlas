## Usage

```bash
atlas panel <subcommand>
```

## Subcommands

### setup

```bash
atlas panel setup
```

Connect the CLI to a Control Panel instance. Prompts for the Panel API URL (e.g., `https://panel.yourdomain.com`).

### status

```bash
atlas panel status
```

Shows the current Panel connection, registered servers, and projects.

### config

```bash
atlas panel config
```

Interactive configuration for integrations:

| Option | Description |
|--------|-------------|
| GitHub App | Creates a GitHub App via manifest flow (opens browser) |
| Cloudflare | Sets API token and account ID for DNS automation |

### server add

```bash
atlas panel server add --host root@server --name production
```

Registers a server with the Panel. Optionally provisions it with the full stack.

| Flag | Description |
|------|-------------|
| `--host` | SSH host |
| `--name` | Server display name |
| `--runtime` | Runtime to provision (`k3s`, `swarm`, `firecracker`) |
| `--provision` | Provision the server after registration |

### server list

```bash
atlas panel server list
```

Lists all registered servers with status, runtime, and IP.
