## Usage

```bash
atlas preview <subcommand> [options]
```

## Description

Create, list, and destroy ephemeral environments tied to git branches. Each preview gets an isolated namespace (K3s), stack (Swarm), or VM set (Firecracker) with its own URL.

## Subcommands

### start

```bash
atlas preview start [options]
```

Creates a preview environment from the current branch.

| Flag | Description |
|------|-------------|
| `--name` | Preview name (defaults to branch name) |
| `--host` | SSH host |
| `--yes, -y` | Non-interactive mode |

### stop

```bash
atlas preview stop --name <name>
```

Destroys the preview environment and cleans up resources.

### list

```bash
atlas preview list
```

Shows active preview environments with age and URL.

## Examples

```bash
atlas preview start                  # Preview from current branch
atlas preview start --name demo      # Custom name
atlas preview stop --name feature-x  # Destroy preview
atlas preview list                   # List all active
```

## URL pattern

```
https://{name}.preview.{domain}
```

A wildcard DNS record (`*.preview.{domain}`) is created during the first preview start.
