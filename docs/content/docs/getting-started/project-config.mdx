---
title: Project Configuration
description: Complete reference for atlas.yaml.
---

Every Atlas project has an `atlas.yaml` file at the repository root. This file defines your services, domains, and infrastructure requirements.

## Minimal example

```yaml
name: myapp
services:
  server:
    type: api
    port: 3000
    domain: myapp.com
```

## Full example

```yaml
name: myapp
org: my-org
domain: myapp.com
platform: linux/amd64

services:
  api:
    type: api
    dockerfile: ./apps/api/Dockerfile
    target: production
    port: 3001
    replicas: 2
    domain: api.myapp.com
    health: /health
    buildArg: NODE_ENV=production

  web:
    type: web
    dockerfile: ./apps/web/Dockerfile
    port: 3000
    domain: myapp.com

  worker:
    type: worker
    dockerfile: ./worker.Dockerfile

  migrate:
    type: worker
    dockerfile: ./Dockerfile
    target: migrate

infra:
  postgres: true
  redis: true
  tunnel: true
```

## Top-level fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Project name. Used as namespace, image tag prefix, and secret name. |
| `org` | string | No | GitHub organization. Inferred from git remote if omitted. |
| `domain` | string | No | Base domain for the project. |
| `platform` | string | No | Docker build platform (e.g., `linux/amd64`, `linux/arm64`). Auto-detected from server architecture if omitted. |

## Service fields

Each key under `services` defines a service name.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | Required | One of `api`, `web`, or `worker`. |
| `dockerfile` | string | `./Dockerfile` | Path to the Dockerfile. |
| `target` | string | | Docker build target stage. |
| `buildArg` | string | | Docker build argument (format: `KEY=VALUE`). |
| `port` | number | | Port the service listens on. Required for `api` and `web`. |
| `replicas` | number | `1` | Number of replicas to run. |
| `health` | string | | Health check endpoint path. |
| `domain` | string | | Public hostname. Triggers DNS record creation and TLS provisioning. |

## Service types

| Type | Behavior |
|------|----------|
| `api` | Backend service. Gets Traefik routing, DNS record, TLS certificate. |
| `web` | Frontend service. Same networking as `api`. |
| `worker` | Background process. No ingress, no domain, no external routing. |

A service named `migrate` is treated specially: Atlas runs it as a one-shot job before deploying other services.

## Infrastructure fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `infra.postgres` | boolean | `false` | Deploy a PostgreSQL instance in the cluster. |
| `infra.redis` | boolean | `false` | Deploy a Redis instance in the cluster. |
| `infra.tunnel` | boolean | `false` | Route traffic through a Cloudflare Tunnel instead of direct IP exposure. |
