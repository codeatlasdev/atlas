## 1. Authenticate

```bash
atlas login
```

Opens GitHub OAuth in your browser. After authorization, the CLI receives a JWT token and stores it at `~/.atlas/config.json`.

For CI environments, pass a token directly:

```bash
atlas login --token $GITHUB_TOKEN --yes
```

## 2. Provision a server

```bash
atlas infra setup --host root@your-vps
```

The CLI prompts you to choose a runtime:

| Runtime | Best for |
|---------|----------|
| Docker Swarm | Small teams, servers with 1-2GB RAM |
| K3s | Teams needing Kubernetes ecosystem (Helm, ArgoCD, HPA) |
| Firecracker | Bare metal with KVM, hardware-level isolation |

Atlas connects via SSH and installs the full stack: runtime, Traefik ingress, TLS, and monitoring.

For non-interactive provisioning:

```bash
atlas infra setup \
  --host root@1.2.3.4 \
  --domain myapp.com \
  --runtime swarm \
  --yes
```

## 3. Deploy

```bash
cd your-project
atlas deploy
```

Builds your Docker images, pushes to GHCR, deploys to the cluster, configures DNS, and provisions HTTPS.

## After deploy

```bash
atlas status              # TUI cluster dashboard
atlas logs api -f         # Stream service logs
atlas env set DB_URL=...  # Set encrypted secrets
atlas preview start       # Ephemeral environment from current branch
```
