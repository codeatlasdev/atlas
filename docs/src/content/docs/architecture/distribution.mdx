## Install Channels

| Channel | Command | Updates via |
|---------|---------|-------------|
| Homebrew | `brew install codeatlasdev/tap/atlas` | `brew upgrade` |
| Shell | `curl -fsSL .../install.sh \| sh` | `atlas self-update` |
| Desktop | Atlas.app (DMG) | Sparkle auto-update |
| Source | `cargo build --release` | Manual |

## Release Pipeline

```
git tag v1.2.0 → GitHub Actions:
  1. Build: aarch64-apple-darwin + x86_64-apple-darwin
  2. Lipo: universal binary
  3. Package: tarballs + SHA256 checksums
  4. Sign: rcodesign (Apple Developer ID)
  5. Publish: GitHub Release + manifest.json
  6. Update: Homebrew tap formula
```

## Version Strategy

All components share the same version (workspace-level).
One tag = one release = CLI + daemon + desktop all in sync.

## Update Channels

| Channel | Cadence | Quality |
|---------|---------|--------|
| stable | 2 weeks | Full QA |
| beta | 1 week | May have bugs |
| nightly | Every push | Dev only |

Switch with: `atlas self-update --channel beta`
