---
title: Headless Mode
description: Run services without TUI for CI/scripts
---

## Usage

```bash
atlas dev --headless
```

Starts all services, streams logs to stdout with ANSI colors, and shuts down cleanly on Ctrl+C.

## Output Format

```
● atlas dev (headless)
  project: myapp
  services: 3

✓ All services started. Press Ctrl+C to stop.

[api  ] Listening on :3000
[web  ] Compiled in 1.2s
[workr] Processing jobs...
```

State changes go to stderr:
```
● api: Starting
● api: Running
● web: Running
```

## Use Cases

- **CI pipelines**: start services, run tests, stop
- **Scripts**: automate dev environment setup
- **Docker**: run inside containers without TTY
- **tmux/screen**: background without TUI overhead
