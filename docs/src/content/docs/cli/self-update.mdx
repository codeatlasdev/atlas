## Usage

```bash
atlas self-update              # Update to latest stable
atlas self-update --check      # Check without installing
atlas self-update --channel beta   # Switch to beta channel
```

## How It Works

1. Fetches release manifest from `releases.atlas.codeatlas.com.br`
2. Compares versions using semver
3. Downloads platform-specific tarball
4. Verifies SHA256 checksum
5. Atomically replaces the running binary
6. Updates daemon if installed alongside

## Installation Method Detection

Atlas detects how it was installed and adapts:

| Method | Behavior |
|--------|----------|
| Homebrew | Tells you to run `brew upgrade atlas` |
| Desktop App | Tells you updates are managed by the app |
| Shell installer | Performs self-update directly |
| Manual | Performs self-update directly |

## Channels

| Channel | Cadence | Stability |
|---------|---------|----------|
| `stable` | Every 2 weeks | Production-ready |
| `beta` | Every week | May have bugs |
