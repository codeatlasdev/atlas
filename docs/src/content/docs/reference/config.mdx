## Top-Level Fields

```yaml
name: string          # Project name (required)
tunnel: TunnelConfig  # SSH tunnel (optional)
services: map         # Service definitions (required)
infra: InfraConfig    # Docker infrastructure (optional)
```

## TunnelConfig

```yaml
tunnel:
  enabled: bool              # default: true
  local_port: u16            # default: 54320
  remote_host: string        # default: localhost
  remote_port: u16           # default: 5432
  ssh_host: string           # required (from ~/.ssh/config)
  keepalive_interval: u16    # default: 15 (seconds)
  keepalive_max: u8          # default: 3
  reconnect_cooldown: u16    # default: 30 (seconds)
```

## ServiceDef

```yaml
services:
  <name>:
    command: string          # required — shell command to run
    port: u16                # optional — port to monitor
    health: string           # optional — HTTP health URL
    critical: bool           # default: false
    depends_on: [string]     # default: []
    enabled: bool            # default: true
```

## InfraConfig

```yaml
infra:
  compose_file: string    # path to docker-compose file
```

## Local Overrides

`atlas.local.yaml` merges on top of `atlas.yaml`. Only specified fields are overridden — everything else keeps the base value.

```yaml
# atlas.local.yaml (gitignored)
tunnel:
  enabled: false
services:
  web:
    port: 3002
    enabled: false
```
