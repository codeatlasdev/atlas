Press `:` to open the command palette — a fuzzy-search dialog for all available actions.

## Usage

1. Press `:` in the dashboard
2. Type to filter commands
3. `↑/↓` to navigate
4. `Enter` to execute
5. `Esc` to cancel

## Available Commands

| Command | Shortcut | Description |
|---------|----------|-------------|
| Restart All | `r` | Restart all services |
| Quit | `q` | Stop all and exit |
| Help | `?` | Show shortcuts |
| Copy Logs | `L` | Copy recent logs |
| Copy for AI | `P` | Copy AI-formatted prompt |
| Copy Errors | `E` | Copy only errors |
| Scroll to Bottom | `G` | Jump to latest logs |
| Scroll to Top | `g` | Jump to first log |
