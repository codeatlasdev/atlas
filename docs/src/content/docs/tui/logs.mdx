Atlas logs are designed for the AI-assisted development workflow.

## Log Levels

Atlas auto-detects log levels from content:

| Level | Detection | Color |
|-------|-----------|-------|
| Error | `error`, `fatal`, `panic`, ANSI red | Red |
| Warn | `warn`, ANSI yellow | Yellow |
| Debug | `debug`, `trace`, ANSI dim | Dim |
| Info | Everything else | Default |

## Copy for AI (`P`)

The `P` key generates a pre-formatted prompt:

```
I'm working on a development environment and encountering issues.
Here are the recent logs from my services:

Project: myapp
Services: api, web, worker

   [api] GET /health 200
   [api] Processing request...
>>> [api] Error: Cannot read property 'id' of undefined
>>> [api]     at UserController.get (/app/src/user.ts:42)
   [api] Request failed

Can you help me understand what's going wrong and how to fix it?
```

Errors are marked with `>>>` and surrounded by context lines (3 before, 2 after).

## Copy Logs (`L`)

Copies the last 3 minutes of logs with timestamps and service headers:

```
# myapp — Dev Logs
# Generated: 2026-07-23 21:30:00
# Services: api, web, worker

── api ──
12:30:01.234 Started on :3000
12:30:02.567 [ERR] Connection refused to database

── web ──
12:30:01.890 Compiled successfully
```

## Copy Errors (`E`)

Copies only error and warning lines across all services.
