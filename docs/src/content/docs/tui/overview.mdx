title: TUI Overview
description: The Atlas terminal user interface
---

The Atlas TUI is a full terminal application — not a script. It provides:

- **Real-time service status** with colored indicators
- **Aggregated log viewer** with per-service filtering
- **Tab navigation** between services
- **Health monitoring** (HTTP, TCP port, process liveness)
- **Toast notifications** with animated spinners
- **Command palette** with fuzzy search
- **Mouse support** (click tabs, scroll)
- **Responsive layout** (adapts to terminal size)

├─────────────────────────────────────────────────┤
│ ? Help  q Quit  r Restart  : Command  tab Next  │  ← Footer

## Starting

```bash
atlas dev                    # Start TUI
atlas dev --dir ./project    # Specify directory
atlas dev --headless         # No TUI, logs to stdout
```
