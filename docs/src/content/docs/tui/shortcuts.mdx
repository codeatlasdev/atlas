---
title: Keyboard Shortcuts
description: All keyboard shortcuts in the Atlas TUI
---

## General

| Key | Action |
|-----|--------|
| `q` | Quit (with confirmation) |
| `?` | Show help modal |
| `r` | Restart all services |
| `:` | Open command palette |
| `Esc` | Close modal/palette |

## Navigation

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Next / previous tab |
| `0-6` | Jump to tab by number |
| `j` / `↓` | Scroll logs down |
| `k` / `↑` | Scroll logs up |
| `G` | Jump to bottom (latest) |
| `g` | Jump to top |

## Logs

| Key | Action | Output |
|-----|--------|--------|
| `L` | Copy Logs | Last 3 minutes, timestamped, grouped by service |
| `P` | Copy for AI | Formatted prompt with error context for Claude/GPT |
| `E` | Copy Errors | Only error/warning lines |

## Mouse

| Action | Effect |
|--------|--------|
| Click tab | Switch to that service |
| Scroll wheel | Scroll logs |
